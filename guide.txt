Repository Setup — Day 1 Commands8.1 .gitignore (Root)Add these to your root .gitignore — especially *.pem. Private keys committed to git is a critical security failure.target/          # Maven build output — never commit compiled classes*.class          # Compiled Java bytecode*.jar            # Built JARs (except release artifacts)*.pem            # RS256 private + public key files — NEVER commit keys.env             # Local environment variables with secrets*.log            # Application log files.idea/           # IntelliJ IDEA project files*.iml.DS_Store        # macOS metadatadocker-compose.override.yml  # Local overrides8.2 First-Time Setup Commands# 1. Clone repo and enter projectgit clone https://github.com/your-org/sentinel.git && cd sentinel# 2. Generate RS256 key pair for JWT (P1 does this once, shares public key only)openssl genrsa -out gateway-service/src/main/resources/keys/private_key.pem 2048openssl rsa -in gateway-service/src/main/resources/keys/private_key.pem \  -pubout -out gateway-service/src/main/resources/keys/public_key.pemchmod 400 gateway-service/src/main/resources/keys/private_key.pem# 3. Start full stackdocker-compose up --build# 4. Load demo fixtures (after stack is healthy)bash fixtures/load_demo_sessions.sh# 5. Run testsmvn test -pl policy-engine-service    # P2: must hit ≥80% coveragemvn test -pl event-store-service      # P3: integration tests with Testcontainers9. Team Rules — Non-Negotiableshared/ module is frozen after Phase 1 Week 2. Any change needs full team agreement and a Flyway migration.Private key (private_key.pem) is NEVER committed. .gitignore must include *.pem from Day 1.P2 must maintain ≥80% unit test coverage on policy-engine-service. No exceptions — this is an AC in the PRD.P3 owns the DB schema. No other team member writes raw SQL migration files. Use shared EventWriter class for inserts.event_writer DB role has INSERT-only on events table. If you need to read events, use sentinel_reader role.No logic in shared/ — only contracts, DTOs, and enums. Business logic stays in its owning service.Replay is READ-ONLY. P4's ReplayEngine must never emit events to the live event store during simulation.Demo fixtures (F01–F03) are P4's responsibility. Run reset_demo.sh before every viva rehearsal.Sentinel Project Setup Guide  |  Team Sentinel  |  Academic Year 2024–25  |  v1.0
